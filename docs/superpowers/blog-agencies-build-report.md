## Data model

```python
class Agency(models.Model):
    slug, name, logo, logo_blend_multiply, tagline, short, about (JSON list),
    rating (Decimal 2,1), review_count, jobs_completed, response_time,
    member_since, services (JSON list), areas (JSON list), contact_name,
    contact_role, contact_phone, reviews (JSON list of {name, date, stars,
    service, comment})

class Article(models.Model):
    slug, title, ingress, header_image (URL), date, read_minutes,
    blocks (JSON list of {type: h2|p|list|image|cta, ...})
```

Both added to `apps/core/models.py` alongside the existing `Flytteforesporsel`
model. `Agency` orders by `name`; `Article` orders by `-date`.

## Seed content

`seed_marketing_content` seeds exactly the 4 agencies (LØFT, relok.,
Flyttefoten, Flytteby) and 3 articles specified in the task, transcribed
verbatim from `lib/blog.ts` for the article `blocks` (every `h2`, `p`,
`list`, `image`, `cta` block in order, for all 3 articles — `image` block
`src`/`alt`/`caption` and each article's `headerImage` URL kept faithfully
in the stored JSON even though the templates render a placeholder box
instead of an `<img>`, per the task's note that no real photography exists
in this project's static files for these). Agency logos reuse the existing
static paths (`images/home/loeftlogo.svg`, `reloklogo.png`,
`flyttefotenlogo.png`, `flytteblogo.png`) already used on the home page —
no duplication.

Idempotency verified twice: once via a dedicated test
(`SeedMarketingContentCommandTests.test_seed_run_twice_does_not_duplicate`,
calling the command twice inside one test and asserting counts stay at
4 agencies / 3 articles), and once manually against the real dev SQLite DB
(ran the command twice from the CLI, confirmed via `manage.py shell` that
counts stayed at 4/3 after the second run).

## Templates

Followed `apps/core/templates/core/home.html`'s conventions: `{% extends
'core/base.html' %}`, `{% load static %}`, BEM-ish semantic class names,
`<!-- ===== SECTION ===== -->` comments, `{% block page_title %}` /
`{% block page_meta %}` / `{% block content %}`.

- **blog/index.html** — "Fra bloggen" hero + `.blog-grid` of `.blog-card`s (placeholder image box, date via `|date:"d.m.Y"`, "X min lesetid", ingress, link via `{% url 'blog_article' article.slug %}`).
- **blog/article.html** — back link, title/meta/ingress, header-image placeholder, then a loop over `article.blocks` switching on `block.type`: `h2`→`<h2>`, `p`→`<p>`, `list`→`<ul><li>`, `image`→placeholder `<figure>` (alt kept as an HTML comment, caption shown as visible `<figcaption>`, not `aria-hidden`), `cta`→`.btn-primary` linking `/flytteforesporsel/`.
- **agencies/list.html** — "Flyttebyråer i Kobly-nettverket" hero + `.agency-grid` of `.agency-card`s (logo respecting `logo_blend_multiply` via a `--blend` modifier class with `mix-blend-mode: multiply`, name, tagline, short, rating via `{{ agency.rating|floatformat:1 }}` + `icon-star`, review_count).
- **agencies/detail.html** — back link, logo/name/tagline header, a stats row (rating, jobs_completed, response_time, member_since), `about` paragraphs, `services`/`areas` as tag lists, a contact block, a reviews grid (reusing `.testimonial-card` styling, with a 5-star row per review using `icon-star` + filled/empty color classes), and a CTA ("Få tilbud fra {{ agency.name }}") to `/flytteforesporsel/`.

Norwegian decimal-comma formatting for ratings was intentionally **not**
built as a custom filter — per the task's explicit instruction, `rating|floatformat:1`
is used as-is (renders e.g. "4.9" with a period, not "4,9"), accepted for v1.

## Known limitations / notes for follow-up

- Rating decimal renders with a period ("4.9"), not a Norwegian comma
  ("4,9") — explicitly deferred per the task brief rather than building a
  custom number filter.
- Article `headerImage` (hotlinked Unsplash URL) and in-article `image`
  block `src` values are stored faithfully in the seeded JSON but rendered
  as solid-color placeholder boxes (`$line` background, `aspect-ratio: 16/9`)
  since no matching real image files exist in this Django project's static
  files — documented inline in both templates with HTML comments.
- The nav's "For flyttebyråer" link now points at `/for-bedrifter/`, which
  currently renders as a blank stub (`apps/core/templates/pages/about/for-business.html`
  equivalent) — fleshing that page out is explicitly a separate, later task
  per the brief, not addressed here.
- A large number of stale/orphaned `python.exe` processes were observed
  accumulated in this environment (unrelated to this task) during manual
  server verification; not touched beyond killing the two that were
  squatting on the port used for verification.
